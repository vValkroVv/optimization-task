# Тесты

Пример запуска тестов:

```bash
pytest run_tests.py
```

Для большинства тестов требуется минимум 2 GPU, однако есть тесты которые требует 4+ GPU. В случае отстутствия достаточного кол-ва карт тесты будут `skipped`.

#### Профайлинг и дебаг режим

Если требуется быстро протестировать какой то сетап (архитектуру модели, заморозку, обертку или другие параметры GigaFSDP) или получить при этом трейсы профайлера, можно воспользоваться скриптом `run_profiler.py`.
Чтобы запустить его в debug режиме (с подробным логом вызовов всех forward/backward хуков) нужно указать ENV переменную `DEBUG_GIGAFSDP=1`. Если получать трейсы не требуется, можно отключить их внутри скрипта.

Пример команды:

```bash
DEBUG_GIGAFSDP=1 python run_profiler.py
```
