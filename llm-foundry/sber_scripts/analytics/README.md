# Training analytics

Инструменты, сопровождающие pretrain-эксперименты:

- [`experimentation/`](experimentation/) — шаблон эксперимента: baseline, общий
  patch и набор отдельных запусков;
- [`stability/`](stability/) — анализ стабильности по TensorBoard-логам и
  чекпойнтам;
- [`performance/`](performance/) — бенчмарки производительности и inference;
- [`statistics/`](statistics/) — общие статистические функции для анализа.
