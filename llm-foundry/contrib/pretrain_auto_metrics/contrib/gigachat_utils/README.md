## Паддинг MLP-весов

Для паддинга MLP-весов в HF-чекпоинте можно использовать скрипт `scripts/pad_mlp_shards.py`.

Важно: скрипт рассчитан на неквантизованный чекпоинт.

Пример запуска:

```shell
python scripts/pad_mlp_shards.py \
  --checkpoint-dir /path/to/hf_checkpoint \
  --only-if-size 10944 \
  --target-size 11264 \
  --update-config
```

Параметр `--only-if-size` задает исходную размерность, которую нужно изменить, а `--target-size` - целевую размерность после паддинга.

При выборе `--target-size` рекомендуется брать значение, которое хорошо делится на 128. Чем больше делителей 2/4/8 у результата деления `target-size / 128`, тем удобнее последующая квантизация модели в fp8 и запуск в inference-фреймворках с тензорным параллелизмом.
