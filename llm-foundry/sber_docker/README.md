## Инструкция по изменению зависимостей в репозитории

Для изменения зависимостей в репозитории вам нужно отредактировать файл `setup.py`, который находится в корневом каталоге проекта. В этом файле вы можете найти секцию `install_requires`, где перечислены все зависимости, необходимые для вашего проекта.

### Шаги для изменения зависимостей:

1. **Откройте файл `setup.py`**: Найдите файл в корневом каталоге вашего проекта и откройте его в текстовом редакторе.

2. **Найдите секцию `install_requires`**: В этом разделе вы увидите список зависимостей, например:
   ```python
   install_requires = [
       'clearml==1.13.2',
       ...
   ]
   ```

3. **Измените версии зависимостей**: Вы можете изменить версии зависимостей, добавив или удалив их, а также указав необходимые версии. Например, чтобы обновить `clearml` до версии `1.14.0`, измените строку на:
   ```python
   'clearml==1.14.0',
   ```

4. **Сохраните изменения**: После внесения всех необходимых изменений сохраните файл.

5. **Проверьте изменения**: Убедитесь, что все зависимости установлены корректно, выполнив команду:
   ```bash
   pip install -e .
   ```

### Примечание о зависимостях `contrib`

Важно следить за зависимостями не только в этом репозитории, но и в репозиториях с `contrib`. Установка зависимостей для `contrib` выполняется отдельно (см. `sber_docker/Docker`). Это поможет избежать конфликтов версий и обеспечит совместимость между различными компонентами вашего проекта. Регулярно проверяйте обновления и изменения в зависимостях, чтобы поддерживать стабильность и безопасность вашего приложения.

### Использование Docker

Для сборки образа с обновленными зависимостями, выполните следующие шаги:

1. **Соберите Docker-образ**:
   ```bash
   docker build -t ваш_образ:тег .
   ```

2. **Запустите контейнер**:
   ```bash
   docker run -it ваш_образ:тег
   ```

Убедитесь, что все зависимости установлены корректно внутри контейнера.
