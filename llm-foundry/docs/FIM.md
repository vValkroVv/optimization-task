# FIM

## Теория

На данный момент поддерживаются 4 различные версии FIM:
* Базовая (случайный выбор начала и конца средней части, [статья](https://arxiv.org/pdf/2207.14255))
* Inline FIM (случайный выбор участка в пределах одной строки)
* Multiline FIM (случайный выбор блока из нескольких строк)
* Syntax-aware FIM, "SFIM" (случайный выбор блока в синтаксическом дереве кодового сэмпла)

Первый метод может быть использован для любого типа текстовых данных, остальные три рекомендуется использовать только для кодовых данных.

В результате экспериментов мы остановились на следующей оптимальной комбинации параметров (так называемый "ГигаКод-сетап"):
* Для не-кодовых данных используется базовый FIM с частотой 0.1
* Для кодовых данных используется смесь Inline FIM и SFIM с частотами 0.375 у каждого

## Практика

Для использования FIM необходимо указать в YAML-конфиге параметр `fim_rates`, который является словарем из частот четырех поддерживаемых методов.
Можно задать как дефолтные значения для всех датасетов:
```yaml
train_loader:
  name: text
  eos_token_id: ${eos_token_id}
  sft_mode: false
  dataset:
    epoch_size: 1062M  # 8.7T tokens epoch
    fim_rates:
      vanilla_fim: 0.1
      inline_fim: 0.0
      multiline_fim: 0.0
      syntax_aware_fim: 0.0
    streams:
      ...
```
так и отдельные значения для конкретного датасета (которые будут использованы в нем вместо дефолтных):
```yaml
      starcoder2:
          local: /mnt/nfs/07-share/tokenized_data/8k_context_128k_digit_tokenizer
          proportion: 8.0
          split: starcoder2_filtered_vocab_rarity
          fim_rates:
              vanilla_fim: 0.0
              inline_fim: 0.375
              multiline_fim: 0.0
              syntax_aware_fim: 0.375
```

Также обратите внимание, что для использования FIM необходимо, чтобы FIM-токены присутствовали в токенизаторе модели. Мы исползьуем следующие FIM-токены:
* `<|fim_prefix|>`
* `<|fim_middle|>`
* `<|fim_suffix|>`

Удобно записывать эти токены под номерами 128253, 128254, 128255 в стандартный токенизатор. Пример готового токенизатора:
`/home/jovyan/abeletsky/models/Qwen2.5-3B-digits-simple-remapped-fim`.
