# Data Profiler Callback

В LLMFoundry появилась возможность более подробно анализировать данные, которые проходят через модель во время обучения. Этот функционал реализован с помощью коллбэка DataProfilerCallback (`llmfoundry/callbacks/data_profiler_callback.py`).

Чтобы активировать этот функционал, добавьте в конфиге обучения две вещи:
1. Добавьте создание коллбэка в секцию `callbacks`
```yaml
callbacks:
  ...
  data_profiler:
    log_interval: 100
    anomaly_threshold: 3.0
    min_samples_for_anomaly: 100
    ema_alpha: 0.001                       # скорость адаптации EMA (на сэмпл)
    outlier_save_path: /path/to/outliers   # по умолчанию (если путь не указан) сэмплы не сохраняются
    max_outlier_file_mb: 100
  ...
```
(указаны значения параметров по умолчанию, соответственно если они вас устраивают то их указание в конфиге не требуется, и можно написать просто `data_profiler: {}`
2. Укажите в секции train_loader флаг для сохранения информации о стримах данных:
```yaml
train_loader:
  ...
  enable_data_profiler: true
  ...
```

Готово! Теперь в TensorBoard (и в логах обучения) будет появляться информация о:

* текущем среднем лоссе (для каждого стрима)
* дисперсии лосса (для каждого стрима)
* количестве сэмплов, встреченных моделью (для каждого стрима)
* долях сэмплов-выбросов с подозрительно высоким/низким лоссом (для каждого стрима)

### Сохранение сэмплов-выбросов

Если указать параметр `outlier_save_path`, то сэмплы с аномально высоким/низким лоссом будут сохраняться на диск по путям:
```
{outlier_save_path}/{stream_name}/high.00000.jsonl
{outlier_save_path}/{stream_name}/low.00000.jsonl
```

Когда размер файла превышает `max_outlier_file_mb` (по умолчанию 100 МБ), происходит автоматический переход к следующим файлам: `high.00001.jsonl`, `high.00002.jsonl` и т.д.

Каждая строка — JSON-объект с полями:
* `step` — номер батча
* `loss` — значение лосса на сэмпле
* `mean` / `std` — текущие среднее и стандартное отклонение на момент детекции
* `z_score` — z-оценка отклонения
* `input_ids` — токены входной последовательности
* `labels` — токены меток (если присутствуют в батче)

По умолчанию сохранение отключено.
