## Measurement limits

CUDA Graph block replay diagnoses warm-cache device work; it does not measure production cache behavior, CPU dispatch, communication or full-step throughput. Eager event/wall latency includes submission and gaps and cannot be subtracted from graph timings to infer CPU cost. Full native measurements include input, transfers, forward/backward, optimizer and lightweight logging; profiling, detailed monitoring, validation, checkpointing, memory snapshots and capture stay off. Kernel-duration sums, GPU idle, communication and elapsed windows overlap and must not be added.

A positive speedup is not an acceptance requirement. Numerical correctness, feature activation, actual supported execution and honest negative/inconclusive results are required. Neither a block comparison nor these crop runs establish convergence, exact native continuation or production PP4/EP32 behavior.
