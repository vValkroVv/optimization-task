After root releases the exclusive eight-GPU lease and a fresh all-eight idle/identity check passes, start the reviewed script with:

```python
from pathlib import Path
import subprocess

attempt = Path("/workspace-SR008.nfs2/vkropotin/optimization-task/runs/cuda-graphs-hybridep-fp8-h100/artifacts/raw/LANE-A/attempts/002")
with (attempt / "supervisor.log").open("ab", buffering=0) as log:
    proc = subprocess.Popen(
        ["bash", str(attempt / "launch.sh")],
        cwd="/workspace-SR008.nfs2/vkropotin/optimization-task",
        stdin=subprocess.DEVNULL,
        stdout=log,
        stderr=subprocess.STDOUT,
        close_fds=True,
        start_new_session=True,
    )
(attempt / "launcher.pid").write_text(f"{proc.pid}\n")
print(proc.pid)
```

The launch script records its child PID, full lifecycle and final exit code. Do not use bare `nohup` or overlap another eight-GPU process.
